# Gopportunities

This repository is a **learning project for Go (Golang)**.

The goal is to learn Go by building a simple API and exploring common tools used in real-world Go projects.

## What is being studied

- Go (Golang) basics
- Building APIs with **Gin**
- API documentation with **Swagger**
- Database access using **GORM**
- Local persistence with **SQLite**

This project focuses on **learning by doing**, not on having a perfect structure from the start.

## Project status

🚧 **In progress**

The code is evolving as the studies progress. The structure may change over time as new concepts are learned.

## Notes
